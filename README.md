# Ansible Lab

Projet d'apprentissage Ansible pour automatiser la configuration de serveurs Linux.

## Structure

- inventory : définition des machines gérées
- playbooks : scénarios d'automatisation
- roles : organisation avancée des configurations

## Playbooks

### ping.yml
Test de connexion entre Ansible et les serveurs.

### install-nginx.yml
Installation et démarrage automatique de Nginx.
